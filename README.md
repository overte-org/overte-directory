# Overte Directory

> [!IMPORTANT]
> This is still a WIP project. Do not run this in an prodection environment.

This is the fourth generation directory server for the overte system, which will include functionality for federation, more advanced contact management and new features, i.e. calendars, groups, and more.

## Building

To build the server install the following tools:

- `cargo`, `rustc` (get MSRV from rust-toolchain.toml)
- `pnpm`

Install webcontent:
```sh
pnpm install
```

Build server:
```sh
cargo build
```

## Contributing

In order to contribute, fork the repository, develop a change in your repo, and create a pull request.

Try keeping changes self-contained and write an overview of your change in your PR description.
